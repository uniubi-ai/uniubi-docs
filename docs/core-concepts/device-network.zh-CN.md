# 机器人网络接入

[English](https://github.com/uniubi-ai/uniubi-docs/blob/main/docs/core-concepts/device-network.md) | **简体中文**

连接真实机器人前，先从设备 App 获取当前的 4G、Wi-Fi 和有线 IP 信息。开发机可以使用 Wi-Fi IP 或有线 IP 登录设备；具体账号和认证方式由设备交付配置决定。

## 从 App 获取设备 IP

| App 中的网络信息 | 用途 |
|---|---|
| 4G IP | 查看设备当前的 4G 网络信息；本指南不将其作为开发机登录入口 |
| Wi-Fi IP | 开发机可使用该地址登录设备 |
| 有线 IP | 开发机可使用该地址登录设备 |

IP 地址可能随设备当前连接的网络而变化。每次连接真机前，应以 App 中显示的当前值为准，不要在脚本或配置中长期写死地址。

## 从开发机登录设备

1. 在 App 中确认当前 Wi-Fi IP 或有线 IP。
2. 确保开发机能够访问对应网络。
3. 使用所选 IP 登录设备。

具体登录账号、密钥或密码由设备交付配置决定，不应写入公开仓库或示例命令。

## 对外服务端口

- 需要从设备外部访问的用户服务，应使用 **`20000–29999`** 端口范围。
- 其他端口为设备内部服务预留，不应由用户应用占用，也不应假设这些端口可以从设备外部访问。

端口范围可能随产品配置调整，使用时以当前设备文档和交付配置为准。

## 大脑与小脑通信

机器人内部的“大脑”和“小脑”通过 `eth0.100` 双向通信。

- High-level SDK 或 DDS 程序运行在机器人“大脑”侧时，必须显式指定 `eth0.100`，才能与“小脑”通信。
- High-level 程序运行在外部电脑时，应选择该电脑上实际连接机器人网络的网卡，不应配置 `eth0.100`。
- 真机 Low-level SDK 仍必须运行在机器人“大脑”侧；网络可达性不会改变这一部署要求。
