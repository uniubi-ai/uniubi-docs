# 连接 USB 与网络外设

[English](connect-peripherals.md) | **简体中文**

## 目标

将 USB 或网络外设连接到机器人大脑，并验证大脑操作系统能够识别或访问该设备。

本文适用于 Creator 版本，只说明对外的外设接入方式，不改变大脑与运控小脑之间的控制链路。

## 接口与使用边界

| 接口 | 连接对象 | 用途与边界 |
|---|---|---|
| `USB-EXT` Type-C | 机器人大脑 | 连接 USB 摄像头、传感器、存储设备及其他受支持的 USB 外设 |
| `USB-BASE` Type-C | 运控小脑 | 小脑预留接口，不作为大脑外设接口使用 |
| RJ45 以太网口 | 机器人大脑 | 连接网络摄像头、激光雷达及其他网络外设 |

两个 Type-C 接口外观相似，但只有板卡丝印标记为 `USB-EXT` 的接口可供大脑侧应用接入外设。识别接口时应以 PCB 丝印为准，不要只依据接口位置判断。

## 1. 连接 USB 外设

1. 如果外设安装要求断电操作，先关闭外设电源。
2. 根据 PCB 丝印找到标记为 `USB-EXT` 的 Type-C 接口。
3. 将外设连接到 `USB-EXT`，不要连接到 `USB-BASE`。
4. 登录机器人大脑，检查 USB 枚举结果：

   ```bash
   lsusb
   ```

5. 如果未发现设备，检查最近的内核日志，并确认线缆、供电要求和 Linux 驱动支持：

   ```bash
   dmesg | tail -n 50
   ```

成功标准是目标设备出现在 USB 枚举结果中，并且应用所需的设备节点或驱动可用。

## 2. 连接网络外设

机器人大脑当前未在对外以太网连接上运行 DHCP 服务，因此连接网线后不会自动为外设分配 IP 地址。

测试通信前：

1. 确认外设当前配置的 IP 地址和子网前缀。
2. 确认机器人大脑上与 RJ45 网口对应的网络接口：

   ```bash
   ip -br link
   ip -br addr
   ```

3. 为该大脑网络接口配置与外设处于同一网段的静态 IP 地址。
4. 确保大脑与外设的 IP 地址不同，并且不与其他设备冲突。
5. 如果外设的 IP 地址可配置，也可以同时调整两端配置。需要持久化大脑侧配置时，应使用当前交付系统规定的网络管理方式。
6. 验证网络可达性：

   ```bash
   ping -c 3 <外设-IP>
   ```

不要直接复制其他机器人的网卡名称或 IP 地址；不同设备的网卡名称和交付网络配置可能不同。

成功标准是机器人大脑已经获得与外设同网段且不冲突的 IP 地址，并能够访问外设 IP。

## 3. 常见问题

### 大脑无法发现 USB 外设

- 确认外设连接的是 `USB-EXT`，而不是 `USB-BASE`。
- 确认外设是否需要独立供电。
- 检查 USB 枚举结果、内核日志和驱动支持情况。

### 网口已经连接，但无法访问外设

- 确认两端已配置同一网段的静态 IP。
- 确认两端 IP 地址不同。
- 重新确认大脑侧选择的网络接口。
- 检查外设的子网掩码、服务端口、防火墙和服务监听地址。

### 能够访问外设，但应用无法打开设备

USB 或网络可达只说明通信链路已经建立。还需要继续检查设备权限、所需驱动或运行库，以及应用自身的配置。
