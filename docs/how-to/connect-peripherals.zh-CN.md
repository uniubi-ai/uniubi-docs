# 连接外设

[English](https://github.com/uniubi-ai/uniubi-docs/blob/main/docs/how-to/connect-peripherals.md) | **简体中文**

## 目标

将 USB 或网络外设连接到机器人大脑，在需要时通过直流电源输出接口为外设供电，并验证连接结果。

本文适用于 Creator 版本，只说明对外的外设接入方式，不改变大脑与运控小脑之间的控制链路。

## 接口与使用边界

| 接口 | 连接对象 | 用途与边界 |
|---|---|---|
| `USB-EXT` Type-C | 机器人大脑 | 连接 USB 摄像头、传感器、存储设备及其他受支持的 USB 外设 |
| `USB-BASE` Type-C | 运控小脑 | 小脑预留接口，不作为大脑外设接口使用 |
| RJ45 以太网口 | 机器人大脑 | 连接网络摄像头、激光雷达及其他网络外设 |
| DC 12V 输出 | 机载供电系统 | 标准 XT30 电源输出接口，12V 输出总功率不高于 36W |
| DC 24V 输出 | 机载供电系统 | 标准 XT30 电源输出接口，24V 输出功率不高于 120W |

![CYVET 外设接口布局](https://raw.githubusercontent.com/uniubi-ai/uniubi-docs/main/docs/how-to/images/cyvet-peripheral-interface-layout.svg)

示意图采用实物照片向左旋转 90 度后的实际安装方向：`USB-BASE` 位于 `USB-EXT` 上方，RJ45 位于两个 Type-C 接口右侧，两个直流电源输出接口位于更右侧。

两个 Type-C 接口外观相似，但只有板卡丝印标记为 `USB-EXT` 的接口可供大脑侧应用接入外设。识别接口时应以 PCB 丝印为准，不要只依据接口位置判断。

## 背部导轨安装尺寸

机器人背盖提供两根同规格导轨，用于安装上装支架或其他外设。两根导轨平行布置，截面规格相同。

![CYVET 背盖导轨安装尺寸](https://raw.githubusercontent.com/uniubi-ai/uniubi-docs/main/docs/how-to/images/cyvet-back-rail-mounting-dimensions.zh-CN.png)

关键机械尺寸如下：

- 单根导轨长度为 212.15 mm，两根导轨中心距为 118.00 mm。
- 每根导轨提供 3 个安装位，相邻安装孔间距为 83.00 mm，首末安装孔跨距为 166.00 mm。
- 导轨截面宽 12 mm、高 13 mm，槽内宽 8 mm，开口宽 5.2 mm，壁厚和底厚均为 2 mm。
- 安装孔底孔直径为 4.5 mm，上部让位直径为 8 mm。

选择滑块、螺母或自制支架时，应同时核对导轨开口和截面尺寸。安装载荷后还应重新检查整机重心、腿部运动空间、线缆走向和紧固可靠性。

## 1. 连接 USB 外设

1. 如果外设安装要求断电操作，先关闭外设电源。
2. 根据 PCB 丝印找到标记为 `USB-EXT` 的 Type-C 接口。
3. 将外设连接到 `USB-EXT`，不要连接到 `USB-BASE`。
4. 登录机器人大脑，检查 USB 枚举结果：

   ```bash
   lsusb
   ```

5. 如果未发现设备，检查最近的内核日志，并确认线缆、供电要求和 Linux 驱动支持：

   ```bash
   dmesg | tail -n 50
   ```

成功标准是目标设备出现在 USB 枚举结果中，并且应用所需的设备节点或驱动可用。

## 2. 连接网络外设

机器人大脑当前未在对外以太网连接上运行 DHCP 服务，因此连接网线后不会自动为外设分配 IP 地址。

测试通信前：

1. 确认外设当前配置的 IP 地址和子网前缀。
2. 确认机器人大脑上与 RJ45 网口对应的网络接口：

   ```bash
   ip -br link
   ip -br addr
   ```

3. 为该大脑网络接口配置与外设处于同一网段的静态 IP 地址。
4. 确保大脑与外设的 IP 地址不同，并且不与其他设备冲突。
5. 如果外设的 IP 地址可配置，也可以同时调整两端配置。需要持久化大脑侧配置时，应使用当前交付系统规定的网络管理方式。
6. 验证网络可达性：

   ```bash
   ping -c 3 <外设-IP>
   ```

不要直接复制其他机器人的网卡名称或 IP 地址；不同设备的网卡名称和交付网络配置可能不同。

成功标准是机器人大脑已经获得与外设同网段且不冲突的 IP 地址，并能够访问外设 IP。

## 3. 为外设供电

DC 12V 和 DC 24V 接口用于为外部设备供电，不承载 USB 或以太网数据。

连接外设前：

1. 确认外设的额定输入电压、功率需求、接头规格和极性。
2. 选择与外设额定输入电压匹配的电源输出接口。
3. 核算功率时应包含外设的启动功率和峰值功率。
4. 12V 输出总功率不得超过 36W，24V 输出功率不得超过 120W。
5. 如果外设还需要与大脑交换数据，应另外连接 USB 或以太网数据链路。

不要将外设接入与其额定输入不匹配的电压。接线前应根据 PCB 丝印和当前交付硬件文档确认电源输出接口。

## 4. 常见问题

### 大脑无法发现 USB 外设

- 确认外设连接的是 `USB-EXT`，而不是 `USB-BASE`。
- 确认外设是否需要独立供电。
- 检查 USB 枚举结果、内核日志和驱动支持情况。

### 网口已经连接，但无法访问外设

- 确认两端已配置同一网段的静态 IP。
- 确认两端 IP 地址不同。
- 重新确认大脑侧选择的网络接口。
- 检查外设的子网掩码、服务端口、防火墙和服务监听地址。

### 能够访问外设，但应用无法打开设备

USB 或网络可达只说明通信链路已经建立。还需要继续检查设备权限、所需驱动或运行库，以及应用自身的配置。

### 数据线已经连接，但外设无法上电

- 确认所选输出电压与外设额定输入电压一致。
- 确认接头规格和极性。
- 根据接口功率上限检查外设的持续功率和启动功率。
- USB 或以太网数据链路正常，不代表独立的直流供电连接正确。
